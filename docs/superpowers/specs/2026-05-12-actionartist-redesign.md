# actionartist.de — Redesign Spec
**Date:** 2026-05-12  
**Client:** Ilian Simeonow — Stuntman & Artist, Dresden  
**Original site:** http://www.actionartist.de/

---

## 1. Goal

Modernize the existing ~2001-built static HTML site into a professional, cinematic portfolio that:
- Preserves **all original content** without loss
- Looks timeless and professional, fitting a Hollywood action/stunt professional
- Ranks well in SEO (German & English)
- Is easy for a developer to maintain and update
- Can have a headless CMS added later without restructuring

---

## 2. Tech Stack

| Concern | Choice | Reason |
|---|---|---|
| Framework | **Astro** | Static output, zero JS by default, excellent SEO, Markdown content collections, not obscure, first-class Vercel support |
| Hosting | **Vercel** | Free tier, auto-deploy from git, global CDN, easy custom domain |
| Content | **Markdown files** in `src/content/` | Developer-editable without a CMS; Astro Content Collections give type safety |
| Styling | **Plain CSS** (scoped per component) | No obscure CSS-in-JS, readable, maintainable by any developer |
| i18n | **Astro i18n routing** (`/de/`, `/en/`) | URL-based language paths, good for SEO; DE is default |
| Fonts | **System fonts** — Georgia (serif) + Helvetica Neue/Arial (sans) | Zero font load time, already looks correct |
| CMS (future) | Keystatic or Decap CMS | Can be added without changing content structure |

**No React.** Astro components are `.astro` files (HTML-like). If interactive islands are needed later, they can be added selectively.

## 5. Hero Video Background

- `<video autoplay muted loop playsinline preload="auto">`
- Starts at `opacity: 0`; transitions to `opacity: 1` on `canplaythrough` event (1.4s ease)
- On error, video element is removed — dark gradient fallback remains
- Overlay: `linear-gradient(to bottom, rgba(0,0,0,0.50) → rgba(0,0,0,0.96))`
- Source: Ilian's own footage — short 10–20s loop, H.264 MP4 + WebM fallback, no audio track, target <8 MB

## 7. SEO

- Astro generates static HTML → fully crawlable
- Each page has unique `<title>`, `<meta name="description">`, `<meta property="og:*">`
- Bilingual pages use `<link rel="alternate" hreflang="de">` and `hreflang="en"` tags
- `sitemap.xml` auto-generated by `@astrojs/sitemap`
- Structured data (JSON-LD) on the homepage: `Person` schema with name, job title, url, sameAs links
- Images served with Astro's `<Image>` component (WebP + lazy loading + width/height to prevent CLS)

---

## 8. Bilingual Strategy

- Default language: **German** (`/de/` or `/`)
- English mirror: `/en/`
- Language switcher in nav: `DE | EN` pill buttons
- URL structure: `/de/biographie/` ↔ `/en/biography/`
- Each content file has a `lang: de` or `lang: en` frontmatter field
- No client-side JS language switching — full page navigations

---

## 9. What's NOT in scope

- Blog / news feed
- User accounts or any backend
